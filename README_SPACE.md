Play (or watch an algorithmic agent) on the **AlienBody** grid: buttons are anonymous IDs until you learn what they do.

- **Human play**: Phase 1 explore → Phase 2 reach the target  
- **Watch AI**: Random / Systematic / Bayesian / Oracle (no API key)  
- **Families**: Remapped → Temporal (F1–F6)
